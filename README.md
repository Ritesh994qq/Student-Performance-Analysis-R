# Student Performance Analysis Using R

## Project Overview
This mini project analyzes student academic performance using statistical methods in R.

## Objectives
- Analyze students' study hours, attendance, previous marks, and final marks.
- Calculate mean, median, variance, and standard deviation.
- Perform correlation analysis and hypothesis testing.
- Apply linear regression to examine factors associated with final marks.
- Visualize student performance using graphs.

## Technologies Used
- R
- RStudio
- ggplot2
- Statistical analysis and data visualization

## Statistical Methods
- Descriptive Statistics
- Pearson Correlation
- One-Sample t-Test
- Linear Regression
- Data Visualization

## Project Files
- `Student Analysis.R` — Main statistical analysis code
- `student_performance_data.csv` — Sample student dataset
- `descriptive_statistics.csv` — Descriptive statistics results
- `regression_results.txt` — Regression model summary

## Dataset
The project currently uses simulated data for 100 students for demonstration and testing.

## How to Run
1. Install R and RStudio.
2. Install the required package using `install.packages("ggplot2")`.
3. Open `Student Analysis.R` in RStudio.
4. Run the script to perform the statistical analysis and generate visualizations.

## Conclusion
This project demonstrates how R can be used to analyze student performance, examine relationships between academic factors, and present statistical results visually.
